# 商談での実演台本(5〜8分)

## 準備(商談の前日まで)

- [ ] 公開中のサイトを開けることを確かめる(スマホとPC)
- [ ] 追加用の写真を1枚、スマホに入れておく(例: 外壁の写真。`work-07.jpg` として送る)
- [ ] Claude のアプリ(または claude.ai/code)で、リポジトリにつながっていることを確かめる
- [ ] 前回の実演で追加した記事が残っていれば、削除しておく

## 流れ

| 時間 | すること | 言うこと(例) |
|---|---|---|
| 0:00 | 公開中のサイトをスマホで見せる | 「工務店さんのサイトの見本です。施工実績やお知らせを、ここから更新します」 |
| 0:30 | Claude に話しかける(写真を添付) | 「先週終わった、みどり野市東町の外壁塗装を施工実績に追加して。築25年、色はベージュ、工期10日。写真はこれ」 |
| 1:00〜3:00 | 待つ間に仕組みを説明する | 「AIが触れるのは文章と写真だけです。デザインは崩れません。書き損じがあると公開前に止まります」 |
| 3:00 | 確認用URLをスマホで開いて見せる | 「まだ本番ではありません。お客様が確認してから公開します」 |
| 4:00 | 「公開して」と頼む(またはマージを押す) | 「これで公開です」 |
| 5:00 | 本番のサイトを再読み込みして見せる | 「実績の一覧の先頭に入りました」 |

## 余裕があれば(止まる様子を見せる)

「地域は書かないで、施工実績を追加して」と頼む。AI が聞き返すか、ビルドで止まって公開されないことを見せる。

## うまくいかなかったとき

- 確認用URLがなかなか出ない → 「ビルドに1〜2分かかります」と言って、先に費用と安全の説明に進む。
- AI が聞き返してきた → 「あいまいなところは推測せずに聞き返す決まりにしてあります」と、そのまま見せ場にする。

## 費用とセキュリティを聞かれたら

- 費用: サーバー代は0円(無料枠)。ドメイン代(年数千円)と、お客様の AI の月額(約3,000円)だけ。
- 安全: ログイン画面やデータベースがないので、WordPress のような攻撃の入口がほぼない。守るのは GitHub・Cloudflare・AI のアカウントで、3つとも二段階認証を必須にします。
