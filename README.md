# みどり野工務店(AIで更新できるサイトの見本)

クロスタが商談で見せるための見本サイトです。会社・人物・電話番号はすべて架空です。

- 作り: Astro 7(静的サイト)+ Cloudflare Pages
- 更新: お客様が Claude Code に話しかけると、文章と写真だけが書き換わり、確認用のURLで見てから公開されます
- AI への決まりごと: `CLAUDE.md`

## 正本について

このフォルダは初版の記録です。公開後は、専用の GitHub リポジトリが正本になります(手順は `docs/publish-guide.md`)。以後の更新はそちらで行い、このフォルダには戻しません。

## コマンド

| コマンド | 内容 |
|---|---|
| `npm run dev` | 手元で表示(http://localhost:4321) |
| `npm run build` | 公開用に焼き上げる(原稿の型の検査込み) |
| `npm run test:guard` | 壊れた原稿がビルドで止まるかの試験(2〜3分) |
| `npm run test:links` | リンク切れの検査 |

## 費用

GitHub・Cloudflare とも無料の範囲で動きます。更新に使う Claude は、お客様がお持ちの契約の範囲です。
